# Output format (writing)

Default output:

1. `Draft:` — the requested prose or artifact.
2. `Assumptions or missing inputs:` — only material issues; omit when none.

Add a compact section outline or claim-evidence map only when the user requests
it, the task is a structural rebuild, or it materially helps audit a long
section. Explain structural choices only when they are non-obvious.

For Chinese-author notes, provide English first. Add brief Chinese notes only
for material choices or unresolved meaning, not as a mandatory duplicate.

If essential evidence or boundary is missing, do not invent. Write a placeholder such as `[Evidence needed: comparator group accuracy on test set X]` and list it under `Assumptions or missing inputs:`.

For `task=submission-package`, replace the default manuscript format with:

1. `Submission readiness:`
2. `Deliverable matrix:`
3. `Draft materials:`
4. `AUTHOR_INPUT_NEEDED:`
5. `Cross-file consistency checks:`
6. `Next actions:`
