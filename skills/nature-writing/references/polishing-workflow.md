# Faithful polishing of existing manuscript text

Use this route for language-only editing, proofreading, faithful translation,
or local restructuring of scientific or submission text the user supplied,
including an existing response letter. Do not load the manuscript drafting
workflow merely because the text belongs to a paper.

## Boundary

- Preserve the complete proposition set, evidence relationships, limitations,
  and citation intent.
- Reorder only material already explicit in the selected text. Do not add,
  remove, strengthen, weaken, or reinterpret a scientific claim, mechanism,
  comparison, causal implication, or uncertainty.
- Distinguish a Chinese draft from Chinese research notes. Translate or polish
  a draft faithfully; use the drafting route only when the user asks to turn
  notes into a new argument.
- Keep text outside the selected scope unchanged.
- Preserve the manuscript's established spelling and punctuation unless the
  user or target journal requires a change; do not enforce mechanical sentence
  lengths or punctuation bans.
- If a structural problem cannot be fixed within these limits, flag it and
  offer a separate drafting pass instead of silently crossing the boundary.

## Workflow

1. Confirm the selected passage and requested operation only when ambiguous.
2. Diagnose the dominant problem: section role, paragraph logic,
   claim–evidence–boundary alignment, terminology drift, or sentence mechanics.
3. Repair at the smallest sufficient level. Prefer sentence edits; locally
   reorder explicit content only when fluency alone cannot solve the problem.
4. Preserve canonical terms, abbreviations, units, notation, citations, and
   figure/table references. Load `terminology-ledger.md` only for multi-section
   work or observed drift, and `ethics.md` only for an actual integrity issue.
5. Return the polished text as prose. Add brief `Revision notes:` only for a
   material structural choice, unresolved ambiguity, fidelity risk, or requested
   style decision. Use side-by-side output only when requested.

## Fidelity gate

Compare the result with the source before returning it:

- Verify every number, unit, statistical symbol, equation, citation,
  figure/table reference, technical term, and defined abbreviation.
- Verify subjects, comparators, populations, conditions, temporal scope,
  negation, and modality.
- Verify claim strength, causality, novelty, generality, and uncertainty.
- Confirm that no claim, evidence, mechanism, limitation, or contradiction was
  silently added or removed.

If a desirable edit fails this gate, preserve the source meaning and report the
issue instead.
