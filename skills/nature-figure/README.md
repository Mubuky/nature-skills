# `nature-figure`

[English](README_EN.md)

面向论文主图、补充图、机制示意图和 graphical abstract 的投稿级科研图工作流。
它从科学结论与证据关系出发，生成或改进 Python/R 图件，并在最终尺寸下做视觉与
数据完整性 QA。

## 适用任务

- 从数据、图注、论文结论或已有图生成可编辑的单图或多面板图；
- 重新设计 Figure 1、方法总览、机制图、workflow 或 graphical abstract；
- 审查图型、视觉层级、配色、字体、面板标签、统计标注与导出格式；
- 从 8 个真实论文项目族的完整 Python 样例与原始成图中选择并保真适配；
- 对 volcano、ROC、marker dot plot、marginal 与 paired 数据使用已有分析型 CSV 工具；
- 生成 SVG/PDF/TIFF/PNG、source-data 映射和投稿前 QA 记录。

整套演示文稿使用 `nature-paper2ppt`；统计推断与报告审查使用
`nature-statistics`。

## 工作原则

1. 先写清核心结论、面板角色、证据层级和目标版面，再选择图型。
2. 从用户指定、现有源文件、项目依赖或已保存偏好推断 Python/R 后端；只有
   选择会实质改变实现时才询问。
3. 最终绘制、版式语义和导出使用同一个源文件与后端；中立查看器和验证器可以
   检查产物。
4. 改造已有高质量样例时，原图是视觉回归基线；保留其项目专属构图、配色、字号、
   线宽、标注与导出设置，不强制套用统一模板。
5. 默认保留全部观测与指定变量。任何排除、聚合或变换都记录规则和前后计数。
6. 在目标栏宽和最终分辨率下检查文字、留白、对齐、色彩可辨性与缩放。

明确要求 AI 示意图时，可以使用宿主提供的图像生成工具制作概念草稿，但不得
将生成内容当作真实实验结果、定量证据或未经核实的科学结构。

## 输入与产出

最好提供原始数据或现有图、图注/claim、目标期刊与尺寸、输出格式，以及是否
需要 source data。信息不全但不影响科学有效性时，技能会说明假设并继续。

典型产出包括：

- 可运行且可复现的绘图源文件；
- 投稿级矢量/位图导出；
- 面板说明、source-data 映射和排除计数；
- 最终尺寸视觉 QA 与仍需人工核实的事项。

详细执行契约见 [SKILL.md](SKILL.md)。内置参考包括图型选择、版式设计、模板
适配、后端选择与 QA；[真实论文保真样例目录](references/paper-pattern-catalog.md)
记录原图、已批准优化、脚本、依赖、回归基线与待确认问题，
`scripts/validate_figure.py` 提供可复现的静态预检。

## 边界

- 不凭空补统计检验、样本量、误差线含义、实验条件或缺失数据；
- 不为渲染方便静默抽样、删点或隐藏不利结果；
- 不把“Nature 风格”简化成固定配色或装饰模板；
- 不因样例难以泛化或存在疑点而删除；先保留原图与原代码，再展示问题和候选修复；
- 私有模板可在本机使用，但不得把私有路径、文件名或来源写入公开产物；聊天中
  可以链接本次任务生成的交付文件。
