# Bundled figure examples

Use the bundled adopted-snapshot assets only as visual or structural references.
Their byte-level provenance and licence boundary are recorded in
[`assets/README.md`](../assets/README.md):

- `assets/chart-atlas/`: compact chart-family previews for choosing an encoding;
- `assets/gallery/`: synthetic multi-panel composition examples;
- `assets/templates/`: reusable data or plotting templates where present.

Select by evidence structure, not superficial resemblance. Rebuild a pattern
with the user's data, labels, statistics, and journal contract. Do not trace,
relabel, or copy a published paper figure.

The upstream snapshot once bundled material from the external
`figures4papers` repository. This derivative does not redistribute that
snapshot because no corresponding licence was found. If a user independently
provides external code or imagery, inspect its licence and use
`asset-adaptation.md` before adapting it.
