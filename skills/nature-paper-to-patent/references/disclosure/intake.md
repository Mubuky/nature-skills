# 边界与输入录入（Step 1）

## 用途

在开始专利挖掘与交底书撰写前，用**少量问题**收敛案件边界。缺失信息可用
`TO CONFIRM` 保留；只可推断不影响技术实质的路由和文档组织。

## 可选开场

```
为便于挖掘专利点与组织交底书，先确认几项边界；可跳过，缺失的技术事实将标记
为待确认，不会代为补造。
```

## 问题序列

### Q1：技术主题或产品模块

```
请用一句话描述本方案所属技术主题或产品模块，例如「多模态检索排序」「工业质检缺陷分级」。
```

### Q2：专利类型倾向

```
是否已有倾向的权利要求类型？方法 / 系统 / 装置 / 暂不确定
```

### Q3：文头联系人

```
交底书文头是否确实需要技术联系人字段？需要时可提供姓名/电话/邮箱；否则写
「待填写」。联系人信息单独保存为交付元数据，不进入 source map 或普通日志。
```

## 汇总

将已确认项用 3–6 行 bullet 复述给用户，再进入 `project_scan.md` 对应的扫描阶段。

技术特征、公式/参数、发明人/权属、公开日期、联系人身份、现有技术差异和法律
状态必须来自源材料或标为 `TO CONFIRM`，不得从常识或上下文补齐。
