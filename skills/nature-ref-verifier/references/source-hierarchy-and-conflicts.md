# Source hierarchy and metadata conflicts

<!-- New in this derivative; see ../../../NOTICE. -->

Use the most work-specific authoritative record available:

1. DOI resolver and publisher/version-of-record landing page.
2. Official conference proceedings, repository, standards body, thesis
   repository, patent office, or institutional report page.
3. Trusted bibliographic registry appropriate to the work, such as Crossref,
   DataCite, PubMed, arXiv, IEEE Xplore, CNKI, or Wanfang.
4. Library catalog or well-curated index.
5. General web search for discovery only; confirm at a stronger source.

No one registry is complete. Record which source controls each disputed field.

Preserve rather than overwrite when sources legitimately describe different
versions or dates:

- online publication versus issue/volume assignment;
- preprint versus accepted manuscript versus version of record;
- conference presentation versus proceedings publication;
- article number versus page range;
- translated/transliterated versus original author or title form;
- revised dataset, report, standard, or book edition.

When a DOI resolves to a different title and author set, treat it as a likely
critical mismatch but verify both the cited work and resolved work before
proposing a replacement DOI.
